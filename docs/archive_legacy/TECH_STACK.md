# Technology Stack

**Kuventory v2.0.0**

## Frontend Core
- **React (v19)**: The core UI library used for building interactive, component-based user interfaces.
- **TypeScript (v5.7)**: Provides static typing to JavaScript, enhancing code quality and developer experience.
- **Vite (v8.1.5)**: A fast, modern build tool and development server.

## Styling & UI Components
- **Tailwind CSS (v3.4.19)**: A utility-first CSS framework for rapid UI development.
- **shadcn/ui**: A collection of beautifully designed, accessible, and customizable React components built on top of Radix UI and Tailwind CSS.
- **Lucide React**: An open-source icon library providing a comprehensive set of scalable SVG icons.
- **next-themes**: Handles dark and light mode theme switching seamlessly.

## State Management & Data Fetching
- **TanStack Query (React Query) (v5.x)**: Handles all asynchronous data fetching, caching, synchronization, and background updates.
- **React Context API**: Used for lightweight global state, such as Authentication status and Theme preferences.

## Routing
- **React Router DOM (v7.x)**: Declarative routing for React, facilitating client-side navigation and code-splitting.

## Forms & Validation
- **React Hook Form**: Performant, flexible, and extensible forms with easy-to-use validation.
- **Zod**: A TypeScript-first schema declaration and validation library, integrated tightly with React Hook Form.

## Data Visualization & Reporting
- **Recharts (v2.15)**: A composable charting library built on React components for building dynamic dashboards.
- **jsPDF & jsPDF-AutoTable**: Generates professional PDF reports directly from the browser.
- **XLSX**: Parses and generates Excel spreadsheets for data export.
